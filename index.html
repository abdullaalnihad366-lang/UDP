Questions

  
Is this public hosting?
No. KILLU X HOST is a private, personal platform for your own bots and projects.

  
How many bots can I run?
As many as your server’s RAM and CPU allow. Eight or more small bots run comfortably on one good server.

  
Which languages work?
Python and Node.js are supported out of the box.

  
What if a bot crashes?
It restarts automatically, and the error shows up in the live logs.
